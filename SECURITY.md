# Security Policy

## Scope

This repository contains Docker Compose configurations, deployment definitions, and supporting files for personal infrastructure.

Vulnerabilities in third-party applications or container images should be reported to their respective maintainers.

## Reporting a Vulnerability

If you discover a security vulnerability caused by this repository's configurations, please report it privately using GitHub's vulnerability reporting feature, if available.

Please do not disclose credentials, tokens, private keys, or other sensitive information in public issues.

## Supported Versions

Only the latest version of this repository's default branch is maintained.

## Disclosure

Security reports will be reviewed on a best-effort basis. No formal response or remediation SLA is provided.
